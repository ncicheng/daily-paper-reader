## 摘要
WOPR 是一个用于研究组织如何做出高风险决策的社会模拟环境，它构建在确定性的、可重放验证的规则引擎之上，并以兵棋推演为载体。我们首先以已发布的卡牌游戏《核战争》对其进行实例化，并依据其发布规则进行校验。我们从军事决策入手，因为它涉及安全问题且需要进一步研究，但设计并非专用于此：将引擎暴露给智能体的决策点契约可跨可验证规则系统复用。现有的社会模拟工作强调角色保真度和合成观点，但缺乏具有可重放验证机制和私有频道协商的可验证规则引擎。WOPR 提供了这种引擎，其契约使每个战略选择都成为明确的智能体决策。该方法与具体社会模拟框架无关；我们采用 Concordia 作为默认驱动游戏的工具。在同一引擎上，WOPR 叠加了一个四级压力阶梯，从沉默到具有结构化承诺的私有单接收者频道，并将每个阵营实例化为一个集体指挥控制系统，而非单个智能体。我们公开所有代码、示例配置和重放数据，网址为 https://github.com/eilab-gt/wopr。

## Abstract
WOPR is a social-simulation environment for studying how organizations make high-stakes decisions, built on a deterministic, replay-validated rules engine and using wargames as the vehicle. We instantiate it first with the published card game Nuclear War, traced against its published rules. We start with military decision-making because of its safety implications and because it needs further study, but the design is not specific to it: the decision-point contract that exposes the engine to agents is reusable across verifiable rule systems. Existing social-simulation work emphasizes persona fidelity and synthetic opinion, but lacks a verifiable rules engine with replay-checkable mechanics and private-channel negotiation. WOPR supplies that engine, and its contract makes every strategic choice an explicit agent decision. The method is agnostic to social-simulation frameworks; we adopt Concordia as the default harness for driving the game. On the same engine, WOPR layers a four-rung press ladder from silence to private single-recipient channels with structured commitments, and instantiates each faction as a collective command-and-control system rather than a single agent. We make all code, example configurations, and replay data publicly available at https://github.com/eilab-gt/wopr.

## 2. 方法论

### 核心思想
- **引擎即规则权威**：确定性规则引擎是合法动作的唯一来源，记录每一次状态迁移；任何声称的结果都可回放与审计。
- **智能体即契约实现者**：任何满足决策契约的实体（单智能体或多智能体系统、甚至派系）都可作为玩家；引擎无需关心智能体内部结构。

### 决策点契约（Decision-Point Contract）
- 引擎暴露三个入口：
  - `pending_decision(state) -> Decision | None`：当前选择点或终止状态。
  - `apply_decision(state, action) -> list[EngineEvent]`：应用动作并自动推进强制步骤至下一个真正选择点。
  - `observe(state, agent_id) -> Observation`：结构化按智能体视图，**保留隐藏信息**（如即使防御者没有反导导弹，也会提供拦截选择，避免暴露手牌）。
- 智能体协议极简：
  ```python
  class DecisionAgent(Protocol):
      def choose(self, observation: Observation, options: list[LegalAction]) -> LegalAction: ...
  ```

### 回合状态机
- 一轮由确定相位序列构成：抽牌（draw）→ 机密（secrets）→ 滑移（slide）→ 宣传（propaganda）→ 威慑（deterrents）→ 部署（place）→ 攻击（attack）→ 拦截（intercept）→ 最后打击（final strike）→ 结束（end）。
- 强制步骤自动推进；**8 种真正选择点**暂停等待智能体决策：部署（PLACE）、发射目标（LAUNCH TARGET）、机密目标（SECRET TARGET）、宣传目标（PROPAGANDA TARGET）、最后打击目标（FINAL STRIKE TARGET）、拦截（INTERCEPT）、修改威慑（MODIFY DETERRENT）、跳过（PASS）。

### 回放验证方法
- **奇偶不变量（parity invariant）**：纯结构性引擎改动必须保持种子化结果逐字节一致；有意的保真性修复造成的偏差必须显式断言。
- **240 局扫描**：3/4 玩家 × 启发式/随机智能体 × 种子 1–60，全部重放比对。
- 采用**双工作树 diff**：对比迁移前后基线智能体输出，证明结构重构不改变结果，或精确定位哪些种子化结果因修复而改变。

### 四级施压阶梯（Press Ladder）
| 层级 | 通信能力 |
|---|---|
| no-press | 仅观察自身游戏状态 |
| press-light | 每轮一条公开声明 |
| multi-turn public | 每轮固定 N 轮次，每名存活智能体每轮发言一次并看到累积记录 |
| full press | 公开 + 私有单接收者频道（whisper）+ 结构化承诺（commitment） |

- 所有层级中，发言均为**仅追踪（trace-only）**，绝不修改游戏状态，回放 JSON 在不同层级间字节一致。
- 承诺采用结构化 schema（如 `{"kind": "stand_down", "target_round": 3}`），仅记录、链接到后续决策，**不做自动违规检测**（靠后验分析）。
- 隐私规则：公开消息对所有存活玩家可见，悄悄话仅对发送者和指定接收者可见；研究者可通过全知 sidecar 读取全部消息。

### 派系指挥与控制原型（C2 Archetypes）
- 每个派系是一个"复合智能体"：内部由多个成员智能体各自观察-推理-提议，经聚合规则坍缩为**一个合法动作**；对外与单智能体无差别。
- 四种原型（沿"释放权力聚何处 + 释放时是否新审议"轴区分）：
  1. **独断权威（Sole-Authority）**：一位执行者决策，可咨询幕僚但可忽略（deference 参数控制）。
  2. **委员会（Council）**：成员投票，满足权重阈值则绑定全体，执行者不可否决；阈值未达时回退到首票。
  3. **分布式（Distributed）**：预授权多名持有者，任一持有者可发起释放（quorum 参数控制）。
  4. **自动化（Automated）**：预装策略，触发条件满足即开火，无释放时审议。
- 每个原型有可配置参数（如权重、阈值、quorum、策略动作 ID 等），同种子确定性保持。

## 6. 主要结论与发现

1. **WOPR 提供了现有社会仿真缺失的底座**：确定性、可回放验证的规则引擎，使"声明的结果"可被独立审计。
2. **决策点契约成功将战略选择"显式化"**：每个战略决策都成为智能体的明确选择，观察保留了隐藏信息（如拦截选项不泄露防御者手牌）。
3. **通信能力可作为独立变量**：四级 press ladder 在不改变引擎的前提下调节通信容量，同一游戏可在不同通信限制下运行，效果差异可归因于通信而非规则。
4. **派系可建模为集体 C2 系统**：四种原型（独断、委员会、分布式、自动化）在同一个契约上收敛为"每决策一个释放动作"，且保持同种子确定性，工程上证明了复合智能体与单智能体的可互换性。
5. **设计可推广**：决策点契约不限于 Nuclear War，可扩展到其他可验证规则系统；方法对具体社会模拟框架无关（Concordia 仅为默认 harness）。

## 7. 优点

- **规则可验证性是核心亮点**：用真实发布的卡牌游戏做载体 + 规则符合性矩阵 + 回放审计，避免了 LLM 社会仿真常见的"叙事可信但不可复核"问题。
- **奇偶不变量机制设计精巧**：双工作树 diff 将结构重构与行为改变解耦，既允许重构又锁定保真度。
- **决策契约极简而通用**：三种入口 + 一个 choose 方法，单智能体与复合派系无缝互换，兼容协议简单清晰。
- **通信与规则解耦**：press 是 trace-only、不改变回放 JSON，使通信效果可以在固定引擎上干净测量。
- **隐私设计的实事求是的处理**：隐藏信息被认真保护（如拦截选项不暴露手牌）；隐私过滤显式建模。
- **C2 原型有文献支撑**：四种原型映射到真实核指挥结构（美国总统权限、巴基斯坦 NCA、预授权、苏联 Perimeter），明确声明为动机而非保真目标，学术态度审慎。
- **开源 + 可复现**：完整代码、示例配置、回放数据公开，附详细复现命令（uv 工具链）。
- **LLM 使用披露详尽**：按 COLM 政策分类披露了实现、实验、写作、审查四个角色，透明度高。

## 8. 不足与局限

- **缺少行为/对照实验**：论文本身是工具介绍，没有跨 press rung、跨 C2 原型的受控行为研究；"通信如何影响决策""不同 C2 如何影响升级倾向"等核心问题留待未来。
- **press 模式未规模化**：press 模式均为单局运行，无批量运行器；多局批量分析未实现。
- **承诺不强制**：结构化承诺仅记录不检测，违约分析完全靠事后人工，自动违规检测是未来工作。
- **C2 覆盖不全**：四种原型中仅委员会有完整工作示例（含真实 last_deliberation 记录）；自动化等原型仅有定义无实例。
- **规则符合性有已知简化**：postal equipment（太空平台、巡航导弹、杀手卫星、航天飞机攻击、MX 导弹分段掷骰）的发射解析使用基础 two-d10 放射性尘埃转盘而非邮政规则指定的六面骰，发射失败概率与实际不同；扩展牌组构成、替代版本、邮政 press 裁决等未经验证。
- **现实映射边界需注意**：论文明确声明对真实核指挥系统不声称保真（伦理声明强调《核战争》是讽刺性商业卡牌），但引用真实指挥结构作为原型可能被误读为模拟真实系统——作者用伦理声明缓解但风险仍在。
- **无算力披露**：LLM 驱动实验所需的计算资源未说明，影响成本可复现性评估。
- **早期阶段定位**：这是 workshop 论文，深度有限；契约、C2 聚合、press 机制均有打磨空间（如严格模式下解析失败即硬失败的设计可能过于脆弱）。
